# Pizza Sales Dashboard | Power BI

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze pizza sales performance. The dashboard helps track key business metrics, identify top-performing products, monitor sales trends, and generate actionable business insights.


## Business Problem

The objective of this project was to analyze pizza sales data and answer key business questions such as:

* Which pizzas generate the highest revenue?
* Which pizza categories perform best?
* What are the sales trends over time?
* Which pizza sizes are most preferred by customers?
* How can business performance be improved using data-driven insights?

## Key Performance Indicators (KPIs)

* Total Revenue
* Total Orders
* Total Pizzas Sold
* Average Order Value
* Average Pizzas per Order

## Dashboard Features

### Sales Performance Analysis

* Revenue tracking
* Order trend analysis
* Sales growth monitoring

### Product Performance

* Best-selling pizzas
* Worst-selling pizzas
* Revenue contribution by product

### Category Analysis

* Sales by pizza category
* Revenue by category

### Size Analysis

* Sales distribution by pizza size
* Customer size preferences
